# 15. Recommended Visual Design Direction

This section is a design recommendation, not information from the
resume.

## 15.1 Overall direction

Create a polished, editorial developer portfolio that feels personal and
contemporary. Avoid a generic template with a large skill cloud and
repetitive cards.

Recommended qualities: - Strong typography and hierarchy. - Generous
whitespace. - Clear project storytelling. - Restrained motion. -
Distinctive but accessible colour palette. - Consistent spacing and card
geometry. - High-quality project visuals.

## 15.2 Suggested palette

A refined neutral palette with a subtle cool accent:

  Token            Suggested value   Usage
  ---------------- ----------------- ----------------------------
  Background       `#F7F8FA`         Main light background
  Surface          `#FFFFFF`         Cards and panels
  Primary text     `#151922`         Headings and body
  Secondary text   `#667085`         Supporting copy
  Accent           `#536DFE`         Buttons and active states
  Accent soft      `#E9EDFF`         Tags and subtle highlights
  Border           `#E7EAF0`         Dividers and outlines
  Dark section     `#111827`         Optional contrast section

Alternative dark theme: - Background: `#0B1020` - Surface: `#121A2B` -
Primary text: `#F5F7FB` - Secondary text: `#A6B0C3` - Accent: `#8EA2FF`

The final theme should be selected consistently rather than mixing
unrelated visual styles.

## 15.3 Typography

Suggested pairing: - Display/headings: **Space Grotesk** or **Sora** -
Body: **Inter** or **DM Sans** - Code/technical labels: **JetBrains
Mono**

Use no more than two primary font families plus an optional monospace
accent.

## 15.4 Layout

-   Desktop: centered content container, approximately 1120--1240 px
    maximum width.
-   Tablet: fluid layout with reduced gutters.
-   Mobile: single-column sections, comfortable touch targets, readable
    line lengths.
-   Use a consistent spacing scale.
-   Avoid horizontal overflow.
-   Keep project details readable and scannable.

## 15.5 Motion and interaction

Recommended: - Subtle section reveal on scroll. - Gentle hover elevation
on project cards. - Small button and link transitions. - Animated active
navigation indicator. - Optional restrained text reveal in the hero. -
Respect `prefers-reduced-motion`. - Avoid excessive parallax,
cursor-following effects, and motion that interferes with reading.
